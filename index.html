Canlı önizleme

GitHub Pages'e nasıl koyulur?
  1. github.com/new → repo adı tam olarak kullanıcıadın.github.io.
  2. index.html indir butonuyla dosyanı indir.
  3. Repo'da Add file → Upload files ile index.html'i yükle, Commit.
  4. 1-2 dk sonra kartın https://kullanıcıadın.github.io adresinde yayında.
  5. İpucu: Yukarıdaki “Kartın linki” alanına bu adresi yazarsan QR doğru çalışır.
