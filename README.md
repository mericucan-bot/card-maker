# Dijital Kartvizit Oluşturucu

Bilgilerini gir, premium dijital kartvizitini canlı önizle ve tek dosya `index.html` olarak indir.
Kendi GitHub Pages'ine (ya da herhangi bir statik hosta) koyunca kart yayında olur.

- Logo gömme, otomatik QR (kart linkinden), vCard indirme
- Aksan rengi + panel teması, TR/EN arayüz
- Bağımlılık yok; tek statik sayfa

Canlı: https://mericucan-bot.github.io/card-maker/
